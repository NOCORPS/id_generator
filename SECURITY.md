# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it by emailing [your-email@example.com](mailto:your-email@example.com).

Please do not report security vulnerabilities through public GitHub issues.

We will acknowledge your report within 48 hours and provide a timeline for a fix.
